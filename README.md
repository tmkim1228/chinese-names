# 중국 이름 배우기 v2.2

병음·한글 독음·훈음으로 중국 한자와 이름을 찾고, 회사 문서 같은 중국어 글을 붙여 넣어 단어의 병음·한국 독음·한국어 뜻·영어 뜻을 보는 오프라인 옥편입니다. GitHub Pages에서 설치형 PWA로 쓰도록 만들었습니다.

## v2.2에서 달라진 점

- 문서 칸의 글을 바꾼 뒤 「AI에게 묻기」·「프롬프트 복사」·「다시 묻기」를 누르면 **지금 입력한 글만** 다시 분석한 다음 질문합니다. 이전 검색의 단어 정리가 새 원문에 섞이지 않습니다.
- 글을 고치면 이전 **AI 설명**은 바로 지워지고, 예전에 받던 답은 새 글 아래에 나타나지 않습니다.
- 서비스 워커 캐시 이름은 `name-dictionary-v2.2-20261109`입니다. 이미 설치한 앱은 “새 버전이 있어요”를 누르면 갱신됩니다.

## v2.1에서 달라진 점

- 「AI에게 묻기」 **단어별 정리**에 한국어 뜻 뒤 **영어 뜻**도 함께 보이도록 안내합니다.
- 형식 예: `快速 kuàisù (쾌속): 빠르게 / fast, quick`
- 서비스 워커 캐시 이름은 `name-dictionary-v2.1-20261109`입니다. 이미 설치한 앱은 “새 버전이 있어요”를 누르면 갱신됩니다.

## v2.0에서 달라진 점

- 회사망·프록시 등으로 **스트리밍(SSE)이 끊기면** 자동으로 일반 응답(`stream:false`)으로 한 번 더 시도합니다. 이후 질문은 스트리밍 없이 바로 요청합니다.
- AI 설정에 **스트리밍 사용** 체크박스가 있습니다. 연결 테스트는 일반 연결 확인 뒤 스트리밍도 짧게 시험합니다.
- 오류 메시지 아래에 HTTP 상태·서버 사유 같은 **짧은 기술 세부**를 회색으로 보여 줍니다.
- 응답이 너무 늦으면(약 120초) 별도 안내를 띄웁니다. xAI 요청에는 `reasoning_effort`를 넣지 않습니다(일부 grok-4 모델이 거부).
- 서비스 워커 캐시 이름은 `name-dictionary-v2.0-20261109`입니다. 이미 설치한 앱은 “새 버전이 있어요”를 누르면 갱신됩니다.

## v1.9에서 달라진 점

- 「AI에게 묻기」의 **AI 설명**이 단어 정리보다 **위**(분석 결과 바로 아래)에 나타납니다.
- 버튼을 누르면 바로 「답변을 받는 중…」이 보이고 그 칸으로 화면이 내려가며, 받는 동안 버튼은 「답변 받는 중…」으로 비활성화됩니다.
- 연결 테스트는 모델 응답 문구를 붙이지 않고 `연결되었습니다 (모델: …)`만 표시합니다.

## v1.8에서 달라진 점

- **AI에게 묻기**는 API 키를 저장하면 앱 화면 안에서 바로 자연스러운 한국어 번역·문맥 설명·단어 정리를 보여 줍니다.
- AI 설정에서 제공 회사(xAI Grok, OpenAI, Google Gemini)와 모델, API 키를 넣습니다. 기본 모델은 `grok-4.7`, `gpt-4o-mini`, `gemini-3.8-flash`입니다.
- 키는 이 기기의 `localStorage`(`chinese-name-app.ai.v1`)에만 저장되며 소스·저장소·배포 파일에는 넣지 않습니다.
- 질문할 때 문서 내용이 선택한 AI 회사 서버로 전송되고, 사용량만큼 요금이 부과됩니다.
- 키가 없으면 설정 창이 열립니다. 예전처럼 질문문만 복사하려면 **프롬프트 복사**를 쓰세요.
- 서비스 워커는 AI API 요청을 캐시하지 않습니다.

## v1.7에서 달라진 점

- 문서 탭에서 자주 쓰는 현대·업무·사무·소프트웨어 UI 단어에 **한국어 뜻**(앱 작성자가 직접 적은 짧은 뜻)을 보여 줍니다. 없는 단어는 영어 뜻(CC-CEDICT)과 글자별 훈음으로 보완하며, 출처를 구분해 표시합니다.
- 분석 뒤에 단어 정리 카드가 나타납니다. 형식은 `快速 kuàisù (쾌속): 빠르게`입니다. 목록을 복사할 수 있습니다.
- 한국어 뜻 표(`data/ko-glosses.json`)는 작아서 핵심 캐시에 포함되며, 단어 사전은 이전처럼 문서 탭에서 내려받습니다.

## GitHub Pages에 올리기

이 폴더(`pwa/`)의 내용을 저장소 **루트**에 올린 뒤 Pages를 활성화하세요.

- HTTPS가 필요합니다.
- 저장소 이름 하위 경로(`https://USER.github.io/chinese-names/`)를 지원합니다. `start_url`은 `.`, `scope`는 `./`이며 모든 자원은 상대 경로입니다.
- 첫 방문 때 핵심 한자·이름 데이터와 한국어 뜻 표를 받고, CC-CEDICT 단어 사전(`data/words.json.gz`)은 문서 탭을 처음 쓰거나 설치 후 백그라운드에서 받아 서비스 워커에 캐시합니다. 그다음부터는 오프라인에서도 문서를 분석할 수 있습니다.
- 서비스 워커가 바뀌면 화면 오른쪽 아래 “새 버전이 있어요”를 눌러 새로고침하세요.
- 복습 목록은 이 브라우저의 저장소에만 남습니다. JSON으로 내보내 백업하세요. 저장된 항목이 5개 이상이거나 마지막 내보내기로부터 7일이 지나면 알림이 뜹니다.

로컬에서 확인하려면 상위 폴더에서 정적 서버를 띄워 하위 경로로 여세요.

```bash
mkdir -p /tmp/serve/chinese-names
cp -a . /tmp/serve/chinese-names
cd /tmp/serve && python3 -m http.server 8765
# http://127.0.0.1:8765/chinese-names/
```

## 데이터와 라이선스

이 앱은 아래 자료를 가공·수록했습니다. 원저작물의 라이선스를 지킵니다.

- **Unicode Unihan Database** — Unicode License. 병음(`kMandarin`, `kHanyuPinyin` 등), 한국 한자음(`kHangul`, `kKorean`), 부수·획수, 간체·번체 이체자.
  https://www.unicode.org/charts/unihan.html
- **libhangul `hanja.txt`** — BSD-3-Clause. 훈음 표제어.
  https://github.com/libhangul/libhangul
- **Chinese-Names-Corpus** (wainshine) — Apache-2.0. 이름용 글자 빈도.
  https://github.com/wainshine/Chinese-Names-Corpus
- **Jun Da character frequency list** — 현대 중국어 글자 빈도.
- **公安部 2020 성씨 순위** — 상위 100 성씨 참고.
- **CC-CEDICT** — MDBG, [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).
  https://www.mdbg.net/chinese/dictionary?page=cc-cedict
  배포 `2026-11-06T08:10:12Z`. 단어 뜻은 영어이며 항목당 최대 3개입니다. 분류사(`CL:`) 줄은 생략했습니다. 병음은 성조 기호로 바꿨습니다.
- **앱 작성 한국어 뜻** — 작성자가 직접 적은 짧은 한국어 뜻입니다. 기존 중한사전을 베끼지 않았고 CC-CEDICT 영어 뜻을 번역·복사하지 않았습니다.

다음자의 한국 독음은 Unihan `kHangul`에 실제로 있는 음과 dictionary의 훈음 꼬리표만 씁니다. 병음과 1:1로 고를 수 있을 때만 하나를 고르고, 확신이 없으면 모든 독음을 `·`로 이어 보여 줍니다.

앱 아이콘의 한자 **名**은 Noto Serif CJK Bold로 그렸습니다.

## 제한

- 독음·간번 변환·단어 분절은 문맥에 따라 달라질 수 있습니다.
- 한국어 뜻은 자주 쓰는 단어를 중심으로 적어 두었으며, 없는 항목은 영어 뜻과 훈음으로 보완합니다. 문장 전체의 자연스러운 번역과 앱·화면 문맥 설명은 「AI에게 묻기」로 앱 안에서 볼 수 있습니다. 이때 문서 내용이 선택한 AI 회사로 전송됩니다.
- 음성은 기기에 설치된 중국어(`zh-CN`) 음성을 이용합니다.
- HSK 태그는 기존 프로젝트 목록을 재사용했습니다.
- 단일 HTML 파일(`중국이름배우기-v2.2.html`)은 `file://`에서 동작하도록 단어 사전을 포함합니다.
